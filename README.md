# Selenium Automation Framework

This project is a Selenium WebDriver based automation framework built using Java and Maven.  
It follows the Page Object Model (POM) design pattern and includes examples of PageFactory, Data Driven Testing, and handling cookies.

---

## Tech Stack

- Java
- Selenium WebDriver
- Maven
- JUnit
- Page Object Model (POM)
